# HU-06: Cálculo de costos

Esta historia de usuario cubre el cálculo de costos con diferentes variantes. El ejercicio pide métodos sobrecargados, y en Python esto se puede representar con parámetros opcionales.

La HU permite calcular un costo base, agregar impuesto y aplicar descuento. También valida que los valores no sean negativos ni incoherentes.

El resultado esperado es un cálculo flexible que pueda ser usado por reservas y servicios especializados.
