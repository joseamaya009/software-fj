# HU-09: Simulación de operaciones

Esta historia de usuario demuestra que el sistema funciona con casos válidos e inválidos. El PDF pide mínimo 10 operaciones completas, incluyendo clientes correctos e incorrectos, servicios correctos e incorrectos, y reservas exitosas y fallidas.

La simulación debe continuar aunque una operación falle. Por eso cada caso se ejecuta dentro de un manejo de excepciones.

El resultado esperado es una prueba práctica donde se evidencie la estabilidad del programa.
