# HU-07: Manejo avanzado de excepciones

Esta historia de usuario responde a uno de los puntos más importantes del PDF: el sistema debe seguir funcionando aunque ocurran errores.

Aquí se definen excepciones personalizadas para clientes, servicios, reservas y cálculos. También se usan bloques `try`, `except`, `else` y `finally`, además de encadenamiento de excepciones cuando un error técnico se convierte en un error del negocio.

El resultado esperado es un sistema estable, que controle los fallos y deje evidencia de lo ocurrido.
