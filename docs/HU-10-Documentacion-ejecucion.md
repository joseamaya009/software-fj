# HU-10: Documentación y ejecución del proyecto

Esta historia de usuario organiza el proyecto para que pueda entregarse y revisarse fácilmente. Incluye la explicación de cómo ejecutar el sistema, qué clases existen y qué principio de programación orientada a objetos cumple cada parte.

También deja claro que el proyecto no usa base de datos. Toda la información se maneja con objetos, listas internas y archivo de logs para eventos y errores.

El resultado esperado es una entrega clara, funcional y defendible ante el docente.
