# HU-08: Archivo de logs

Esta historia de usuario permite registrar eventos y errores importantes en un archivo. El ejercicio prohíbe usar base de datos, pero sí permite usar archivos para guardar eventos y errores.

El log sirve como evidencia de que el sistema registró operaciones correctas, errores controlados y situaciones relevantes durante la ejecución.

El resultado esperado es un archivo de trazabilidad que ayude a revisar qué pasó en la simulación.
